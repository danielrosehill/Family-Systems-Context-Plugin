# Sources

Raw material, verbatim: voice-note transcripts, imported notes, session notes the user
chooses to keep, messages. One file per item, named `YYYY-MM-DD-<slug>.md`, with the
frontmatter described in [`../docs/method.md`](../docs/method.md#sources).

Sources are never edited after they are written. Actor files and the overview link here for every event they record.
